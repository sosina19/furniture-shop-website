# UI/UX Design

## Main Navigation

```text
Home | About Us | Products | Order | Contact Us
```

## Home

Include:

- Business identity
- Short introduction
- Featured/new products
- Product categories
- Clear Order action
- Contact and Telegram action

## Products

Include:

- Search
- Category filtering
- Product cards
- Image
- Name
- Price
- Availability
- Featured/new indicators

## Product Details

Include:

- Image gallery
- Name
- Description
- Price
- Availability
- Estimated availability days where relevant
- Standard colors
- Standard materials
- Standard dimensions
- Customization information
- Reviews
- Order Now
- Contact/Telegram

## Ordering

### From product

```text
Product
  ↓
Order Now
  ↓
Prefilled order form
  ↓
Customer can change options/customize
  ↓
Name + Phone + Email
  ↓
Submit
```

### From navigation

```text
Order
  ↓
Empty order form
  ↓
Select product
  ↓
Options load
  ↓
Customize
  ↓
Name + Phone + Email
  ↓
Submit
```
